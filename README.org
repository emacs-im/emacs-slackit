#+title: Slackit
#+options: toc:nil num:nil

Slackit is an independent Appkit-based Slack client for Emacs.  Its
=slackit-= namespace coexists with =emacs-slack=.  The current daily-use slice
includes multi-account roots, room/thread history, exact user profiles and
direct-message entry, realtime updates, semantic =RET=/mouse action spans,
structured mentions, circular avatars, standard and workspace emoji,
protocol-led native code highlighting, reaction chips, account-isolated
image/video/audio/document media, Appkit-owned composer file uploads,
send/edit/delete, explicit read marking, optional Evil integration, and
context-safe Transient menus.

Slackit requires Emacs 29.1, =browser-session=, =transient=, and the
=browser-session= helper executable.  Configure optional stable IDs in
=slackit-account-ids= and run
=M-x slackit=; an account without private auth opens an isolated browser login.
=M-x slackit-register-account= remains a session-only headless fallback.

Architecture, security, lifecycle, and deferred-scope contracts are in
[[file:docs/architecture.org][docs/architecture.org]].
